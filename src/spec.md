# Specification

## Summary
**Goal:** Rebrand the storefront as Twin Roots Foods and update the Home page to be export-focused with premium sections, visuals, and an easy WhatsApp contact path.

**Planned changes:**
- Update site-wide header and footer branding text to “Twin Roots Foods” while keeping existing navigation and e-commerce routes intact.
- Revise the Home page hero to use the exact headline “From Indian Farms to Global Tables” and add export/wholesale-focused supporting copy; keep the hero image as a static generated asset.
- Add/replace Home page sections after the hero (in order): Our Products, About Us, Why Choose Us, Certifications, Bulk Inquiry, Contact (with WhatsApp button).
- Ensure “Our Products” highlights Indian Spices, Dry Fruits, and Dehydrated Powders (Onion, Garlic, Ginger, Moringa).
- Add export-trust positioning content (two brothers story, quality/hygiene/sourcing points) and show placeholder certification logos/names.
- Integrate premium, export-appropriate static visuals across sections (products, farmer/harvest, hygienic processing) with responsive behavior and English alt text.
- Add a WhatsApp entry point (required in Contact; optional secondary placement in header/footer) that opens a wa.me link without removing existing navigation items.

**User-visible outcome:** Visitors see Twin Roots Foods branding, an export-oriented Home page with the specified sections and premium imagery, and can quickly reach the Bulk Inquiry flow and contact via WhatsApp while all existing pages (Home, Shop, Export Inquiry, Cart, Checkout) continue to work.
